# Практична 09. Дві архітектури під один сценарій

**Тиждень 11**

Сценарій видається на парі.

**Що зробити**

1. Опишіть розв'язання **клієнт-серверною** архітектурою:
   компоненти, хто з ким говорить, де живе стан.
2. Опишіть **одноранговою**.
3. Намалюйте обидві схеми (mermaid у `README.md` або зображення).
4. Таблиця порівняння: єдина точка відмови, масштабування,
   складність, вартість, безпека.
5. **Оберіть одну**, обґрунтуйте у 5–7 реченнях.
6. Назвіть, що змусило б вас **змінити рішення**.

**Здати:** `praktyka/09-arkhitektury/`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Обидві архітектури описані конкретно | 2 |
| Схеми зрозумілі | 2 |
| Порівняння за критеріями | 2 |
| Вибір обґрунтований, названо умову зміни | 2 |
