# Практична 02. Послідовна реалізація та профіль

**Тиждень 2**

Базова реалізація, відносно якої міряється все інше.

**Що зробити**

1. Реалізуйте задачу послідовно, без бібліотек.
   Розмір підберіть так, щоб один прогін тривав **5–15 секунд**.
2. Замір через `time.perf_counter()`, **три прогони**, у звіт — усі три.
3. Заміряйте **окремо** послідовну частину (запис результату)
   і обчисліть її частку у відсотках.
4. `cProfile` — знайдіть гарячу функцію.
5. Збережіть результат у файл.

**Здати:** `1-poslidovno/`, `zamiry.md`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Працює, результат зберігається | 2 |
| `perf_counter`, три прогони в таблиці | 2 |
| Характеристики машини вказані | 1 |
| Послідовна частка **виміряна**, не вгадана | 2 |
| Профіль знято, гарячу функцію названо | 1 |

⭐ Порівняйте прогноз із практичної 01 з виміряним. Поясніть розбіжність.

⚠️ Робота без умов вимірювання (процесор, ядра, розмір, кількість
прогонів) не оцінюється вище 3 балів.
