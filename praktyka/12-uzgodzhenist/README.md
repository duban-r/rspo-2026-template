# Практична 12. Розходження копій і кворум

**Тиждень 14**

Показати конфлікт і полагодити його.

**Що зробити**

1. Три вузли зі спільним значенням.
2. Асинхронна реплікація: запис підтверджується одразу,
   копії оновлюються потім.
3. **Заміряйте вікно неузгодженості** в мілісекундах.
4. Влаштуйте конфлікт: одночасні записи різних значень.
5. Реалізуйте **одну** стратегію вирішення, обґрунтуйте вибір.
6. Реалізуйте кворум W + R > N, покажіть, що конфлікту немає.
7. `zvit.md`: який компроміс обрали і що втратили.

**Здати:** `praktyka/12-uzgodzhenist/`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Реплікація працює на трьох вузлах | 2 |
| Вікно неузгодженості заміряне | 2 |
| Конфлікт відтворено | 1 |
| Стратегія вирішення реалізована й обґрунтована | 2 |
| Кворум працює | 1 |

⭐ Версійні вектори: відрізнити справжній конфлікт від запізнілого запису.
