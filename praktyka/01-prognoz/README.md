# Практична 01. Прогноз за законом Амдала

**Тиждень 1**

Ще нічого не запускаємо. Спершу — прогноз.

⭐ **Прогноз — це обґрунтована здогадка, а не точний розрахунок.**
Ви ще не писали код цієї задачі, і не повинні знати відповідь точно.
Сенс вправи саме в тому, що на тижні 4 ви побачите, наскільки
помилились, і поясните чому. Немає правильного чи неправильного
числа сьогодні — є тільки обґрунтоване чи ні.

## Що таке множина Мандельброта

[Стаття у Вікіпедії](https://uk.wikipedia.org/wiki/Множина_Мандельброта) —
якщо математичний опис незнайомий, для цієї практичної досить
розуміти структуру задачі, а не формули.

Для кожної точки зображення окремо повторюється проста формула,
і рахується, скільки разів можна повторити, перш ніж число «втече»
в нескінченність — це число стає кольором пікселя.

- **Кожна точка рахується сама по собі**, без залежності від
  сусідніх — це та частина, яку можна роздати на ядра.
- **Зібрати всі точки в одне зображення й записати у файл** —
  робиться один раз, наприкінці, і не ділиться на частини. Це і є
  та сама послідовна частка з кроку 3 нижче. Запис файлу не залежить
  від кількості ядер, тож розумно припустити невеликий відсоток
  від загального часу — але число і обґрунтування ваші.

**Що зробити**

1. Зафіксуйте характеристики машини:

   ```python
   import os, platform
   print(platform.processor())
   print("логічних ядер:", os.cpu_count())
   ```

   Фізичну кількість ядер дізнайтесь окремо (PowerShell):

   ```powershell
   Get-CimInstance Win32_Processor | Select-Object NumberOfCores, NumberOfLogicalProcessors
   ```

2. Оберіть задачу семестру. За замовчуванням — множина Мандельброта.
   Своя задача можлива за двох умов: **обмежена обчисленнями**
   і **ділиться на незалежні частини**. Погодити до тижня 3.

3. Оцініть частку коду, яка **не розпаралелюється**. Обґрунтуйте.

4. За законом Амдала обчисліть стелю для вашої кількості ядер
   і для нескінченної.

5. Запишіть **прогноз числом**: у скільки разів очікуєте прискорення.

## Шаблон `prognoz.md`

Формат довільний, але якщо не знаєте, з чого почати — заповніть це:

```
Машина: [процесор], [N] логічних ядер (з них [M] фізичних)
Задача: множина Мандельброта (або своя — назвіть яку)
Послідовна частка (оцінка): ~X%, бо [обґрунтування]
Стеля за Амдалом для N ядер: [число]
Стеля за Амдалом для нескінченності: 1/X%
Прогноз: очікую прискорення приблизно у Y разів
```

**Здати:** `prognoz.md`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Характеристики машини зафіксовані | 2 |
| Послідовна частка визначена й обґрунтована | 3 |
| Розрахунок за Амдалом правильний | 2 |
| Прогноз сформульований числом | 1 |

⭐ Побудуйте графік S(N) для s = 0.01, 0.05, 0.1 при N від 1 до 1024.
