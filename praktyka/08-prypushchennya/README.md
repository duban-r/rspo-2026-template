# Практична 08. Зламати хибне припущення

**Тиждень 10**

Вісім хибних припущень — не список зі слайда, а те, що ламається.

**Що зробити**

Видається робочий клієнт-серверний приклад.

1. Запустіть як є, переконайтесь, що працює.
2. Оберіть **одне** з восьми припущень.
3. **Зламайте його навмисно**: розірвіть з'єднання, додайте затримку,
   надішліть завеликий об'єкт, зупиніть сервер посеред запиту.
4. Зафіксуйте, що саме сталося: повідомлення, **час до реакції**,
   чи відновилось само.
5. Полагодьте: таймаут, повтор із витримкою, обробка помилки.
6. Покажіть, що після виправлення система переживає той самий злам.

**Здати:** `praktyka/08-prypushchennya/`, `zvit.md`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Приклад запущено | 1 |
| Припущення зламано, поведінку зафіксовано з числами | 3 |
| Виправлення працює | 2 |
| Названо, яке припущення й чому воно хибне | 2 |

⭐ Зламайте два припущення одночасно.
