## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `Без порушень: 5 із 5` уже до виправлення | помилка не проявилась на вашому залізі | збільшіть `ZAMOVLEN_NA_PROTSES` або `PROTSESIV` — файл сам це підказує |
| після виправлення порушення лишились | під замком не вся потрібна ділянка | перевірка й списання мають бути під **тим самим** замком, в одному `with` |
| інваріант 2 полагоджено, а 1 — ні | замок стоїть лише навколо присвоєнь | рядок `if` теж має бути всередині `with` |
| один процес відвантажив усе, решта — 0 | замок навколо всього циклу — процеси працюють по черзі | звузьте ділянку до одного замовлення |
| `TypeError: ... takes 4 positional arguments but 5 were given` | замок передано в `args`, але не додано у функцію | `def obrobyty_zamovlennya(zalyshok, vidvantazheno, vidmov, nasinnya, zamok):` |
| `NameError: name 'zamok' is not defined` у процесі | функція бере замок як глобальну змінну | передавати тільки через `args` — новий процес не бачить змінних головного |
| процеси запускаються без кінця / `RuntimeError: ... bootstrapping phase` | код запуску поза `if __name__ == "__main__":` | увесь запуск — тільки під цією перевіркою |
| програма зависла | замок узято й не звільнено | тільки `with zamok:`, без ручних `acquire()` |
