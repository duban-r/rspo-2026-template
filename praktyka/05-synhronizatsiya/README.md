# Практична 05. Гонка даних

**Тиждень 5**

Знайти, відтворити й полагодити помилку, якої не видно.

**Що зробити**

Видається `zlamane.py` — перекази між рахунками в кількох потоках.
Сума грошей у системі має лишатися сталою.

1. Запустіть як є. Сума **зійдеться** — гонки не видно.
2. Додайте `sys.setswitchinterval(1e-6)` і покажіть, що вона є.
3. Знайдіть критичну секцію, назвіть її у звіті.
4. Полагодьте блокуванням. Перевірте при різних інтервалах.
5. Заміряйте, **наскільки повільніше** стало.

**Здати:** `praktyka/05-synhronizatsiya/`, `zvit.md`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Гонку відтворено, числа до і після | 2 |
| Критичну секцію названо правильно | 2 |
| Виправлення працює | 2 |
| Заміряно вартість блокування | 1 |
| Пояснено, чому гонки не було видно одразу | 1 |

⭐ Влаштуйте взаємне блокування навмисно, покажіть його й полагодьте
впорядкуванням блокувань.
