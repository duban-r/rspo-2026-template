# Практична 11. Хто був першим: логічний час і вибори координатора

Тема 11 · до **8 балів** · практика — друга пара й початок третьої ·
з середини третьої пари — **кожен ділиться результатом**

Три вузли ведуть короткий робочий чат: хтось питає, хтось відповідає, хтось уточнює.
Годинники вузлів розходяться — рівно так, як розходяться у ваших ноутбуків.
Ви побачите, як «відповідь» стає раніше за «питання», напишете годинник Лемпорта,
який це виправляє, і з'ясуєте, чого він **не вміє**. А потім уб'єте координатора
й заміряєте, скільки система живе без нього.

Усе локально, стандартна бібліотека, повідомлення — UDP. Ні Docker, ні Redis.

## Крок 2. Годинник Лемпорта (15 хв)

Відкрийте `godynnyk.py`. Три методи класу `Lamport` повертають `self.L`, нічого не змінюючи.
Допишіть три правила з теми:

1. перед кожною власною подією — `L = L + 1`;
2. надсилання — теж подія; це `L` іде разом із повідомленням;
3. отримавши повідомлення з `Lm` — `L = max(L, Lm) + 1`.

```

```

✔ `пройдено 5 з 5` і `✔ годинник правильний`.

Закрийте всі три вузли (`Ctrl+C`), запустіть знову — **з новим `godynnyk.py`** — і зведіть:


✔ «ЗА ФІЗИЧНИМ ЧАСОМ» — ті самі **7** порушень: годинники як брехали, так і брешуть.
✔ «ЗА ЛОГІЧНИМ ЧАСОМ» — `порушень причинності: 0`.

## Крок 3. Конкурентні події (15 хв)

Подивіться на таблицю за логічним часом. Знайдіть дві події, у яких **L різні**, але
жодна не могла вплинути на іншу. Підказка: подія вузла, яка сталася до того, як він
отримав хоч щось, і подія іншого вузла десь посередині розмови.

Перевірте свою пару:

```
python zvesty.py --para B3 C1
```

✔ На ноутбуці викладача:

```
B3: L=4 · подумав, хто вільний
C1: L=1 · запустив обчислення
КОНКУРЕНТНІ: жодного ланцюжка «сталося раніше» ні в той, ні в інший бік.
   Зверніть увагу: L у них різні — і це нічого не означає.
```

І для порівняння пара, яка пов'язана:

```
python zvesty.py --para A2 C3
```

✔ `ПРИЧИНА → НАСЛІДОК: A2 → C2 → C3`.

У звіті: ваша конкурентна пара, вивід `--para` і одне речення — чому `L(C1) < L(B3)`
не означає, що C1 «було раніше». Номери подій у вас можуть бути іншими — беріть зі своєї таблиці.

## Крок 4. Координатор помирає (20 хв)

Вузли весь цей час обирали координатора алгоритмом задираки: перемагає живий
із найбільшим номером, тобто C. Координатор раз на 0,5 с шле «пульс»; хто не чув
його 1,5 с — оголошує вибори.

Закрийте термінал C (`Ctrl+C`) і дивіться на A і B:

✔ `координатор C мовчить 1.51 с` → `вибори: C мовчить → питаю старших` →
у B `★ я — координатор (без координатора було 2.05 с)`, в A `координатор тепер B`.

Поверніть C, не повторюючи розмову:

```
python vuzol.py --imya C --tilky-vybory
```

✔ C спершу приймає B, одразу бачить, що B молодший, і забирає координацію:
у B — `старший C живий — віддаю координацію`.

Тепер заміряйте, як це залежить від таймауту. Перезапустіть **усі три** вузли з
`--tilky-vybory --taimaut 0.6`, убийте C, запишіть «без координатора було…».
Повторіть для `--taimaut 3`.

✔ На ноутбуці викладача:

| `--taimaut` | Без координатора |
|---|---|
| 0,6 с | 1,16 с |
| 1,5 с | 2,01–2,05 с |
| 3 с | 3,53 с |

У звіті: звідки береться різниця між таймаутом і часом без координатора? Чому б
тоді не поставити таймаут 0,1 с — що ви втратите? (Відповідь числами — у ⭐2.)

## Якщо щось пішло не так

| Що бачите | Що це означає | Що робити |
|---|---|---|
| `error: remote shablon already exists` | адресу шаблону вже додано раніше | одразу `git fetch shablon` |
| вузол вічно пише `чекаю сусідів` | двох інших вузлів ще не запущено | запустіть усі три |
| `OSError: [WinError 10048]` | старий вузол із тим самим ім'ям ще живий | закрийте його термінал |
| `журналів zhurnal-*.jsonl немає` | `zvesty.py` запущено не в теці стенда або до кроку 1 | `cd praktyka/11-logichnyi-chas`, спершу вузли |

| `❌ порушено` у властивості Лемпорта | одне з правил неправильне | `perevirka_godynnyka.py` покаже яке |
| `w32tm` пише про помилку доступу | служба часу вимкнена | візьміть число викладача й напишіть про це у звіті |
| Числа таймаутів трохи інші | планувальник ОС і перевірка раз на 0,05 с | важливе співвідношення, а не мілісекунди |
