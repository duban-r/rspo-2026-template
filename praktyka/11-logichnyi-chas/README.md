# Практична 11. Логічний час Лемпорта

**Тиждень 13**

Хто був першим, якщо годинники різні.

**Що зробити**

1. Три процеси, що обмінюються повідомленнями через Redis.
2. Кожен веде **годинник Лемпорта** за трьома правилами:
   - перед власною подією: `L += 1`
   - при відправленні: додати `L` до повідомлення
   - при отриманні `Lm`: `L = max(L, Lm) + 1`
3. Кожен пише журнал: `[час] процес подія → номер`.
4. Зведіть журнали в одну таблицю за логічним часом.
5. **Знайдіть дві конкурентні події** й доведіть, що вони конкурентні.
6. Порівняйте з упорядкуванням за системним часом — покажіть, де воно бреше.

**Здати:** `praktyka/11-logichnyi-chas/`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Три процеси обмінюються, журнали ведуться | 2 |
| Усі три правила реалізовані | 2 |
| Зведена таблиця | 1 |
| Конкурентні події знайдено й доведено | 2 |
| Розбіжність із системним часом показана | 1 |

⭐ Реалізуйте векторний годинник і покажіть, що він **виявляє**
конкурентність, а лемпортівський — ні.
