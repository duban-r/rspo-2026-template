## Глосарій

| У курсі | Українською | Суть |
|---|---|---|
| host / device | процесор / карта | дві сторони дороги |
| kernel | ядро | функція, яку виконує кожен потік |
| grid-stride loop | цикл із кроком сітки | потоків менше, ніж даних: кожен бере кожну N-ту точку |
| atomic operation | атомарна операція | неподільне оновлення, апаратно |
| shared memory | спільна пам'ять блока | швидка пам'ять для потоків одного блока |
| coalesced access | об'єднаний доступ | сусідні потоки читають сусідні адреси одним запитом |
| pinned memory | закріплена пам'ять | пам'ять, яку система не перемістить, — DMA бере її одразу |
