Остання практична.

**Що зробити**

1. Зареєструйтесь на Google Cloud Skills Boost (акаунт Google
   у вас уже є з практичної 07).
2. Пройдіть **один безкоштовний курс** із хмарних основ,
   отримайте completion badge. Скріншот у звіт.

4. Один графік: усі стани задачі, **логарифмічна шкала**.
5. `pidsumok.md`, пів сторінки: три розриви й пояснення кожного.
