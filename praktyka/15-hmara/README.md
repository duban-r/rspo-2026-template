## Крок 2. Підсумкова таблиця (30 хв)

З вашого `zamiry.md` — по одному найкращому числу на кожен стан:

```markdown
## Підсумок семестру: Мандельброт 1200×800, max_iter=300
Процесор: …, ядер фізичних / логічних: … / …

| # | Стан | Час, с | Прискорення | Тема |
|---|---|---|---|---|
| 1 | послідовно | | ×1 | 2 |
| 2 | потоки (N = …) | | | 3 |
| 3 | процеси (N = …) | | | 4 |
| 4 | Numba `@njit` | | | 6 |
| 5 | Numba `parallel=True` | | | 6 |
| 6 | GPU у Colab (лише ядро / з копіюванням) | | | 7 |
| 7 | 4 працівники через брокер | | | 10 |
| 8 | 3 вузли, мережа +5 мс, шматок 1 | | | 13 |
```

Для порівняння — ноутбук викладача (AMD, 8/16): потоки ×1,0 · процеси ×4,7–5,9 · `@njit` ×63–66 ·
`parallel=True` ×378–564 · 4 працівники через брокер ×2,6–3,5 · 3 вузли при +5 мс і шматку 1 — **×0,8**.

## Крок 3. Графік (20 хв)

```python
import matplotlib.pyplot as plt

stany = ["послідовно", "потоки", "процеси", "@njit", "parallel", "GPU", "брокер", "+5 мс"]
pryskorennia = [1, 1.0, 5.3, 64, 450, 0, 3.0, 0.8]      # ← ВАШІ числа; 0 — якщо стану немає

plt.figure(figsize=(9, 4))
plt.bar(stany, pryskorennia)
plt.yscale("log")
plt.axhline(1, color="grey", linewidth=0.8)
plt.ylabel("прискорення відносно послідовного (лог. шкала)")
plt.title("Мандельброт 1200×800 — вісім станів однієї задачі")
plt.tight_layout()
plt.savefig("grafik.png", dpi=150)
```

Немає `matplotlib`: `pip install matplotlib`. Не ставиться — намалюйте в Google Sheets із логарифмічною віссю.
