# Практична 07. GPU і модель CUDA

**Тиждень 7**

Виконується в браузері: Google Colab або середовище NVIDIA DLI.

**Що зробити**

1. `!nvidia-smi` — запишіть модель карти.
2. Ядро на `@cuda.jit`. Перевірка меж обов'язкова.
3. ⚠️ `cuda.synchronize()` перед кожним заміром — інакше виміряєте
   запуск, а не обчислення.
4. **Три окремі числа:** копіювання туди, обчислення, копіювання назад.
5. Порівняйте з усіма реалізаціями з процесора.
6. Прогоніть для 300×200, 1200×800, 3000×2000 — покажіть, як
   змінюється частка копіювання.
7. `vysnovky.md`: за якого розміру GPU починає окупатись.

**Здати:** `5-gpu/mandelbrot_gpu.ipynb` — зошит **із результатами**.

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Ядро працює, збіг з еталоном | 2 |
| `cuda.synchronize()` є, замір коректний | 2 |
| Три складові часу заміряні окремо | 2 |
| Три розміри, показано зміну частки копіювання | 1 |
| Названо розмір, за якого GPU окупається | 1 |

⭐ Розмір блока 8×8, 16×16, 32×32. Поясніть через розмір варпу.
