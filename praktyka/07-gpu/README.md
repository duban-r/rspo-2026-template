## Крок 1. Ядро (20 хв)

Ядро — функція, яку виконує **кожен потік**. Той самий внутрішній цикл, що на тижні 2;
обидва зовнішні цикли зникли — їх замінили потоки.

```python
@cuda.jit
def mandelbrot_gpu(out, xmin, xmax, ymin, ymax, max_iter):
    x, y = cuda.grid(2)                              # хто я в сітці
    if x >= out.shape[1] or y >= out.shape[0]:       # ⚠️ перевірка меж — обов'язкова
        return
    cx = xmin + (xmax - xmin) * x / out.shape[1]
    cy = ymin + (ymax - ymin) * y / out.shape[0]
    zx = 0.0
    zy = 0.0
    n = 0
    while zx * zx + zy * zy <= 4.0 and n < max_iter:
        zx, zy = zx * zx - zy * zy + cx, 2.0 * zx * zy + cy
        n += 1
    out[y, x] = n
```

Запуск — у квадратних дужках **конфігурація сітки**: скільки блоків і скільки потоків у блоці.

```python
import numpy as np

XMIN, XMAX, YMIN, YMAX = -2.0, 1.0, -1.2, 1.2
MAX_ITER = 300
W, H = 1200, 800

potokiv = (16, 16)                                   # 256 потоків у блоці
blokiv = ((W + 15) // 16, (H + 15) // 16)

d_out = cuda.device_array((H, W), dtype=np.int32)
mandelbrot_gpu[blokiv, potokiv](d_out, XMIN, XMAX, YMIN, YMAX, MAX_ITER)
out = d_out.copy_to_host()

import matplotlib.pyplot as plt
plt.figure(figsize=(9, 6))
plt.imshow(out, cmap="magma", extent=(XMIN, XMAX, YMIN, YMAX))
plt.colorbar(label="ітерацій")
plt.show()
```

✔ Знайома картинка Мандельброта. Чорна або порожня — див. «Якщо щось пішло не так».
✔ `blokiv` виходить `(75, 50)` — це 3750 блоків по 256 потоків, майже мільйон потоків
на мільйон точок. Кожен потік рахує **одну** точку.

## Крок 2. З чим порівнювати: еталон у тому ж зошиті (15 хв)

Свої числа з ноутбука ви привезли, але **порівнювати результат** треба з тим, що
порахувала ця сама машина — інакше різниця в останньому біті змішається з різницею
в залізі.

```python
from numba import njit, prange

@njit(parallel=True, cache=True)
def mandelbrot_cpu(W, H, xmin, xmax, ymin, ymax, max_iter):
    out = np.empty((H, W), np.int32)
    for j in prange(H):
        for i in range(W):
            cx = xmin + (xmax - xmin) * i / W
            cy = ymin + (ymax - ymin) * j / H
            zx = 0.0
            zy = 0.0
            n = 0
            while zx * zx + zy * zy <= 4.0 and n < max_iter:
                zx, zy = zx * zx - zy * zy + cx, 2.0 * zx * zy + cy
                n += 1
            out[j, i] = n
    return out

mandelbrot_cpu(16, 16, XMIN, XMAX, YMIN, YMAX, MAX_ITER)          # компіляція
ref = mandelbrot_cpu(W, H, XMIN, XMAX, YMIN, YMAX, MAX_ITER)

rozbizhnyh = int((out != ref).sum())
print("розбіжних точок:", rozbizhnyh, "з", W * H)
```

✔ **Нуль або одиниці** розбіжних точок. Обидві версії рахують у подвійній точності
однаковою формулою, тож збіг має бути точним або майже точним.
✔ **Тисячі** розбіжних (близько 0,26 % усіх точок) — ви десь перейшли на `float32`.
Це не помилка, але це вже інша задача: див. ⭐2.

## Крок 3. Три числа — головне вимірювання теми (15 хв)

⚠️ Запуск ядра **не чекає** його завершення: керування повертається одразу.
Без `cuda.synchronize()` ви заміряєте час **запуску**, а не обчислення — і отримуєте
«прискорення» в тисячі разів, якого немає.

```python
import time

def zamir_gpu(W, H, blok=(16, 16), n=3):
    host = np.empty((H, W), np.int32)
    blokiv = ((W + blok[0] - 1) // blok[0], (H + blok[1] - 1) // blok[1])
    best = None
    for _ in range(n):
        t0 = time.perf_counter()
        d_out = cuda.to_device(host)
        cuda.synchronize()
        t_tudy = time.perf_counter() - t0

        t0 = time.perf_counter()
        mandelbrot_gpu[blokiv, blok](d_out, XMIN, XMAX, YMIN, YMAX, MAX_ITER)
        cuda.synchronize()
        t_yadro = time.perf_counter() - t0

        t0 = time.perf_counter()
        res = d_out.copy_to_host()
        t_nazad = time.perf_counter() - t0

        if best is None or sum(best[:3]) > t_tudy + t_yadro + t_nazad:
            best = (t_tudy, t_yadro, t_nazad, res)
    return best

t_tudy, t_yadro, t_nazad, out = zamir_gpu(W, H)
razom = t_tudy + t_yadro + t_nazad
print(f"копіювання туди   {t_tudy*1000:8.2f} мс")
print(f"обчислення        {t_yadro*1000:8.2f} мс")
print(f"копіювання назад  {t_nazad*1000:8.2f} мс")
print(f"разом             {razom*1000:8.2f} мс   копіювання = {100*(t_tudy+t_nazad)/razom:.0f} %")
```

✔ Три різні числа, кожне більше за нуль.
✔ Перший запуск ядра **довший за решту** — компіляція під вашу карту. Тому й тут
мінімум із трьох прогонів, як усі шість тижнів.
✔ **Мінімум для зарахування — ви тут.**

Окремо покажіть у зошиті саму пастку — один раз, щоб було видно різницю:

```python
d = cuda.to_device(np.empty((H, W), np.int32))
cuda.synchronize()
t0 = time.perf_counter()
mandelbrot_gpu[blokiv, potokiv](d, XMIN, XMAX, YMIN, YMAX, MAX_ITER)
bez = time.perf_counter() - t0        # ⚠️ виміряли лише запуск
cuda.synchronize()
z = time.perf_counter() - t0          # справжній час
print(f"без synchronize {bez*1000:.3f} мс · з synchronize {z*1000:.3f} мс")
```

✔ Різниця — у десятки й сотні разів. Це і є «прискорення», яке щороку потрапляє
в чужі звіти.

| Що бачите | Що це означає | Що робити |

| `CudaSupportError: Error at driver init` | карта зникла посеред сесії (буває після простою) | Середовище виконання → Підключитися заново, виконати зошит спочатку |

| `CudaAPIError: ... invalid configuration argument` | у блоці більше за 1024 потоки (наприклад, 64×64) | 16×16 = 256 або 32×32 = 1024, не більше |
| `TypingError` усередині ядра | у ядро потрапив список, `print`, функція NumPy чи виклик звичайної функції | у ядрі — лише числа, масиви й арифметика |

| Сесія відвалилась, усе зникло | Colab вимикає неактивні зошити | зберігайте на GitHub після кожного великого кроку, не наприкінці |
| Карти немає взагалі й не буде | — | локально: `NUMBA_ENABLE_CUDASIM=1` — той самий код виконається **звичайним Python**.
