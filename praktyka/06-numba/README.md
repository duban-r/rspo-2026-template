# Практична 06. NumPy та Numba

**Тиждень 6**

Найбільший виграш дає не паралелізм.

**Що зробити**

1. `pip install numpy numba`
2. Векторизована версія. ⚠️ Сітку зробіть **точно тією самою**:
   `np.linspace(a, b, n, endpoint=False)`. Порівняйте з еталоном
   і **порахуйте розбіжні точки**.
3. Версія з `@njit`. Заміряйте **окремо** компіляцію й виконання.
4. Версія з `@njit(parallel=True)` і `prange`.
5. Таблиця всіх реалізацій від практичної 02.
6. `vysnovky.md`: чому векторизація дала менше за компіляцію.

**Здати:** `4-numba/`
