# Практична 13. Двофазна фіксація зависає

**Тиждень 15**

Правильний протокол із підручника має стан без виходу.

**Що зробити**

Береться реалізація 2PC із комплекту підручника
(`figs-and-code.zip`, розділ 08).

1. Запустіть координатора й двох учасників. Проведіть транзакцію.
2. Запустіть ще раз і **вбийте координатора між фазами** —
   після того, як учасники відповіли «так».
3. Покажіть стан учасника, який завис.
4. Дайте відповідь у звіті: **що учасник може зробити сам?**
5. Опишіть, які є виходи з цієї ситуації та чого вони коштують.

**Здати:** `praktyka/13-vidmovostiykist/`, `zvit.md`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| 2PC запущено, звичайний сценарій працює | 3 |
| Координатора вбито між фазами, стан показано | 3 |
| Пояснено, чому учасник не може вирішити сам | 2 |
