# Практична 10. Сокети проти черги

**Тиждень 12**

Той самий обмін двома способами.

**Що зробити**

1. **Сокети.** Клієнт-сервер зі структурованими даними.
   ⚠️ Обов'язково розв'яжіть проблему **меж повідомлень** —
   довжиною на початку або роздільником. Покажіть, що великий
   об'єкт доходить цілим.
2. **Черга.** Той самий обмін через Redis:
   `docker run -d -p 6379:6379 redis`
   Продемонструйте, що отримувача можна вимкнути й увімкнути,
   а повідомлення дочекається.
3. Заміряйте затримку одного повідомлення в обох варіантах.
4. Додайте **другого** отримувача. Покажіть різницю черги
   й публікації-підписки.
5. `zvit.md`: для якої задачі обрали б кожен варіант.

**Здати:** `praktyka/10-komunikatsiya/`

**Критерії — 8 балів**

| Критерій | Балів |
|---|---|
| Сокетна версія, **межі повідомлень оброблені** | 3 |
| Черга працює, вимкнення отримувача показано | 2 |
| Затримка заміряна в обох | 1 |
| Різниця черги й підписки показана | 1 |
| Обґрунтований вибір під задачу | 1 |

⭐ Запустіть `rpc2.py` із комплекту підручника. Поясніть роль `pickle`
і чому він небезпечний від недовіреного джерела.
